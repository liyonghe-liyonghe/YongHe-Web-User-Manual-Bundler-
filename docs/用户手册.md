# 泳和-网页/用户手册合成器 · 用户手册

版本：`0.8.7` · 许可：MIT · 仓库地址：待定（发布者创建仓库后填入）

## 1. 这是什么

一款桌面应用，把你手头的多种格式文档（PDF/Word/PPT/WPS/ODF/RTF/Markdown/TXT/HTML 等）整理编排成一本网页手册，最终导出为**一个 HTML 文件**。样式、图片、脚本、文档都内嵌在这一文件里，拷给别人、离线打开都能看。

## 2. 界面三栏

- **左栏 · 输入**：添加文档所在文件夹，或把 `.html` 文件从系统文件管理器拖入；列出已收集的页面；选择导出路径。
- **中栏 · 导航配置**：把页面拖入导航树，分组、排序、双击改名、右键调整；选择外壳风格。
- **右栏 · 预览**：实时预览手册效果。

顶栏提供「导出单文件 html 网页」按钮与「帮助」按钮，并可切换 13 种界面语言。

## 3. 快速上手

1. 点「添加文件夹」选择文档目录，或直接拖入 HTML 文件。
2. 在中栏把页面拖进导航树，编排章节顺序与层级。
3. 点「选择输出路径」指定导出位置。
4. 点「导出单文件 html 网页」生成手册。
5. 用浏览器打开导出的 HTML；断网亦可查看。

## 4. 支持的输入格式

PDF、DOC、DOCX、WPS、ODT、ODP、PPT、PPTX、RTF、Markdown、TXT、HTML/MHTML。旧版二进制格式（doc/wps/ppt）为启发式文本提取，排版还原有限；PDF 优先按页高清渲染，动态库缺失时自动降级为文本提取。

## 5. 编码与乱码

对 TXT/MD/RTF 等纯文本与 RTF 代码页，程序用 19 种编码候选逐一试解，并以汉字/假名/谚文字频门控判定正确结果。常见的 GBK、Big5、Shift-JIS、EUC-KR 等旧编码文档可自动还原，无需手工转码。

## 6. 多语言说明

界面与增量辅助控件支持 13 种语言（简体中文、繁体中文台湾/香港、英语、法语、俄语、西班牙语、葡萄牙语、阿拉伯语、日语、韩语、希腊语、德语），阿拉伯语界面整体 RTL 翻转。**页面正文的语种由你的素材决定，程序不翻译正文。**

## 7. 缺图缺件自动补齐

当页面引用的本地图片等资源缺失时，程序会先在已登记的目录集中自动搜索同名文件补齐；仍找不到时弹窗兜底，由你选择来源文件夹。

## 8. 常见问题

- **导出的手册打不开 / 样式丢失**：请用现代浏览器（Chrome/Edge/Firefox）打开；单文件体积较大时加载稍慢属正常。
- **PDF 页面模糊**：确认 `pdfium.dll` 与程序同目录；缺失时程序会降级为文本提取，排版还原度下降。
- **超大体量手册导出**：体积超阈值时程序会给出拆分确认，建议按分卷导出以降低浏览器内存占用。
